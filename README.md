Independent data projects, one repo. Each is self-contained: own README, own docs, own data.

### E-commerce Sales Dashboard
Five sales-manager questions over 131 weeks of product sales: where revenue comes from, seasonal peaks,
whether promos pay, what stockouts cost, and which products are dying. Runs in the browser via shinylive.
→ [`ecommerce-sales-dashboard/README.md`](./ecommerce-sales-dashboard/README.md)

### Google Play Store — Marketspace Analysis
2.3M apps, one CSV, no assumptions. A cell-by-cell walk from raw Kaggle export to clean findings on
what drives ratings, installs, and app survival.
→ [`google-playstore-analysis/README.md`](./google-playstore-analysis/README.md)

### Understanding Indian EcoPolitical Growth Over the Years
R Shiny dashboard over 49 World Bank indicators — macro economics *and* governance — tracing India
1960→today. Config-driven ETL, no API keys.
→ [`indian-ecopolitical-growth/BUILD_PLAN.md`](./indian-ecopolitical-growth/BUILD_PLAN.md)
