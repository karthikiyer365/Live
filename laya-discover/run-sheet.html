Next run · Arm D

Fine-tune Laya on the training rows

Start from Laya's official Apple-Silicon fine-tune script and change only what our evaluation rules require. Each step has a gate; a failed gate stops the run before hours are spent.

Official script doesArm D does insteadWhy
Trains on its own benchmark datasetOur 11,670 training rows from splits.csv, raw text, same typed question as Arm BSame rows and question as every other arm
Calibrates on a random 10% of training rows (lines 257–261)Trains on all training rows; calibrates on validationA random slice holds reworded siblings of training tickets: a leak
Saves a checkpoint each epoch, never scores validationScores validation after each epoch and keeps the bestThe epoch is chosen on validation, never on test
Exports a checkpointAlso writes predictions/arm_d_*.csv in the shared formatThe same score() judges every arm

Build the training items

setup

Turn each training ticket into a Laya item: raw subject + body, the four-type question, and its true type as the target. Read laya.common (build_sequence, proper_reward) first so the format matches the script.

Full run, seed 42, script defaults

main run
optimizer
AdamW, weight decay 0.01
learning rate
encoder 2.5e-5 · head 1e-4 · cosine decay to 1e-6
batch
1 ticket × 32 accumulated = 32 per update → 365 updates per epoch
epochs
up to 4; score validation after each, keep the best
loss
cross-entropy + Laya's proper-scoring RL term (unchanged)
Stop rulemore than 3 h per epoch, or out of memory at micro-batch 1 → move this step to Colab, nothing else changes

Calibrate on validation

logged selection

Fit one temperature on validation with the script's own fit_temperature, then re-score ECE and the auto-route line for the 95% target. Logged as a selection step.

Gatekeep the temperature only if ECE falls and log-loss does not rise (the baseline's rule)

Two more seeds

variance

Same settings, seeds 43 and 44. Fine-tuning scores can swing between seeds, so a single run can't prove a 1-point win.

Gatereport mean and spread across the 3 seeds; the chosen model is fixed after this
